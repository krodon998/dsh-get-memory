# Get记忆（dsh-aire-memory）— DSH 记忆插件

Get记忆插件：对话开始时自动拉取 GitHub 指定仓库的内容并注入上下文；对话结束时提取值得长期记住的新信息写回并提交；左栏快捷面板实时查看状态，设置界面进行详细配置。

名字是双关：**Get** 记忆（取回记忆）+ **Git** 记忆（GitHub 仓库里的记忆）。

## 特性

- **自动拉取注入**：每次对话开始（新建 / 恢复会话）自动拉取指定 GitHub 仓库的指定文件并注入上下文（排序号默认 100，位于所有运行时上下文之前）；断网自动回退磁盘缓存；注入内容自动花括号消毒，仓库文件带模板语法（如 `{{User}}`）也不会炸。
- **文件权限中心**：设置页「同步文件列表」一键拉取仓库当前文件清单，每个文件「只读 / 读写」可视化勾选（新文件默认读写），注入与写回统一按这张权限表走；每次拉取也会自动盘点（新文件自动加入、含模板语法的自动跳过）。
- **多文件自动写回**：对话结束（回合停 30 秒无新消息，或会话关闭）时，插件自行调用模型提取「值得长期记住的新信息」，对所有「读写」文件按文件产出变更、逐个先取最新 SHA 再提交。无实质变化不提交、不动文件；SHA 冲突自动重取重试一次；跨端「传话文件」只在有需要传话/回话时动。
- **左栏快捷面板**：一颗小心心图标，实时查看拉取状态、写回结果、令牌状态，一键「立即拉取」，开关自动写回，内置最近操作记录。
- **原生设置页**：DSH 设置里新增「Get记忆」专属页面，仓库、文件权限、触发范围、模型等全部字段可视化配置，保存即生效；插件列表里也有配置入口。
- **触发与范围**：每 N 次对话写回一次（N 可填，1 = 每次）；应用于「全部会话 / 排除列表 / 仅列表」；每次写回最多文件数可限。
- **回合写回指示**：每回合结束，消息下方一行小字——「记忆已写回 ✓ / 整理中… / 无新记忆 / 写回失败」，悬停看详情，可在设置里关闭。
- **全局变动提示**：写回有变动时，输入框下方弹一条「记忆已更新」小条，几秒自动消失（简洁模式也看得到，可开关）。

## 快速开始

1. 安装插件（文件方式或插件市场）；
2. 打开左栏「Get记忆」面板（或设置页），在令牌框粘贴你的 GitHub 细颗粒度 PAT（**只给目标仓库 Contents 读写权限**），点保存；
3. 在设置页填好仓库与文件（默认已配好一组可用值）；
4. 正常聊天：对话开始自动读，结束自动写。

## 底层逻辑（使用攻略）

### 令牌是怎么用的

插件按以下顺序找令牌，找到即止：

1. **DSH 凭据库**（`AIRE_MEMORY_GITHUB_TOKEN`，面板保存的令牌就存在这里，推荐位置）；
2. **环境变量**（同名）；
3. **插件配置的 `githubToken` 字段**（引导用：一旦在配置里填了，插件首次加载时自动把它迁移进凭据库）。

令牌只会被用于「读取 / 写入你配置的那一个仓库」，**绝不写入仓库任何文件**；写回前还会对内容做密钥形态脱敏。

### 读取链路

`agent/created` 事件（每次「上岗」）→ 并行拉取仓库文件（GitHub Contents API）→ 更新内存缓存 + 磁盘缓存（`~/.dsh/cache/aire-memory/snapshot.json`）→ 通过 `systemPrompt.context()` 在每次模型组装时注入最新内容。拉取失败不报错：回退缓存（标注过期），缓存也没有就注入「暂不可用」占位。

### 写回链路

`agent/turn-stopping`（回合结束）→ 防抖 30 秒（期间有新消息就取消）→ 或 `agent/disposed`（会话关闭）立即执行 → 插件自行调用模型（用当前会话模型 / 默认模型）提取新记忆，输出更新后的完整目标文件 → **先 GET 拿最新 SHA** → **PUT 提交（SHA 锁）** → 409 冲突自动重取重试一次 → 成功后本会话立刻看到新内容。

只对**根会话**（主对话）写回；子代理 / 工作流会话不写。所有失败仅记日志，绝不打断对话。

## 配置（均有默认值，可直接用）

| 字段 | 默认 | 说明 |
|---|---|---|
| `repo` | `krodon998/Aire-memory` | 记忆仓库（owner/repo） |
| `branch` | `main` | 分支 |
| `fileModes` | 旧字段自动迁移 | 文件权限表 `[{file, mode: 'ro'/'rw'}]`：注入取全部，写回只取 rw；设置页「文件权限」卡片管理 |
| `ledgerFile` | `长期记忆账本.md` | 主账本（多文件写回时排最前） |
| `injectOrder` | `100` | 上下文排序（数字小靠前；运行时上下文从 110 起） |
| `tokenRef` | `AIRE_MEMORY_GITHUB_TOKEN` | 凭据库 / 环境变量名 |
| `githubToken` | 空 | 引导令牌（secret），首次加载自动迁移进凭据库 |
| `autoDiscoverFiles` | `true` | 每次拉取盘点仓库新 .md 并加入权限表（读写），含 `{{` 模板语法的跳过 |
| `writebackEnabled` | `true` | 自动写回开关 |
| `writebackEveryN` | `1` | 每 N 次对话写回一次 |
| `sessionPolicyMode` | `all` | 应用范围：`all` / `exclude` / `include` |
| `sessionPolicyIds` | 空 | 排除 / 仅限的会话 id 列表 |
| `maxWriteFiles` | `5` | 每次写回最多处理的「读写」文件数 |
| `writebackDebounceMs` | `30000` | 回合结束后的写回防抖（毫秒） |
| `maxTranscriptChars` | `16000` | 送入提取器的转录上限（取尾部） |
| `minConversationChars` | `80` | 低于此长度不提取 |
| `extractProvider` / `extractModel` | 空 | 提取模型覆盖；留空用会话模型 / 默认模型 |
| `requestTimeoutMs` | `15000` | 拉取 / 写入超时（毫秒） |
| `showPanelIcon` | `true` | 显示左栏快捷面板图标 |
| `showTurnIndicators` | `true` | 显示回合写回指示 |
| `showGlobalNotice` | `true` | 写回变动时输入框下方的小条提示 |
| `historyLimit` | `50` | 面板内操作记录保留条数 |

设置页与快捷面板里改动以上任意字段（图标/指示开关除外）都会保存为运行时覆盖，即时生效、重启保留。

## 更换令牌

1. GitHub 生成新的细颗粒度 PAT（仅目标仓库 Contents 读写）；
2. 面板或设置页令牌框粘贴新令牌保存（自动覆盖凭据库旧值，保存时即做仓库读验证），或直接改 `~/.dsh/.credentials.yaml` 里 `AIRE_MEMORY_GITHUB_TOKEN` 的值（重启 DSH 后生效）；
3. 旧令牌在 GitHub 上单独作废，互不影响。

## 本地开发

```bash
# 客户端半边是拼接式 ModuleLoader bundle（无构建依赖）：
node scripts/build-client.mjs   # 由 src/client/*.js 生成 client.js
node --check lib/index.v8.js    # 宿主半边语法检查
```

宿主半边入口见 package.json 的 `main`（纯 JS ESM）；客户端半边声明见 `dsh.client` 与 `exports["./client"]`。
